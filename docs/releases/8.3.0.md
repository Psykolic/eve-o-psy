# EVE-O Preview 8.3.0 — A forja mudou de casa (migração para Forgejo)

Esta versão marca a migração da Fase 3: o desenvolvimento saiu do GitHub e passou a viver num
**Forgejo self-hosted**. O aplicativo em si **não muda** — mesma interface, mesmas thumbnails, mesmo
comportamento da 8.2.2.

### Por que uma minor

Porque a mudança é de infraestrutura, não de código: repositório, CI, auto-merge, agente autônomo e
backup mudaram de dono. Publicar como patch esconderia isso.

### O que mudou na prática

| Antes | Agora |
|---|---|
| Repositório no GitHub | **Forgejo** (192.168.18.24:3000) como fonte da verdade |
| CI no GitHub Actions | CI no Forgejo, runner self-hosted em host mode (**sem Docker**) |
| Auto-merge em workflow do GitHub | `auto_merge.py` por timer, mesma política |
| Agente via `gh` | mesmo código, shim `gh` → Forgejo |
| GitHub como tudo | GitHub **só recebe** `main` e tags, e publica as releases |

### Ganhos medidos na fase

- **−64,1% de CPU idle** com 7 clientes (1,45% → 0,52% de um core) — entregue na 8.2.2 e mantido aqui;
- CI em ~40 s no runner próprio, sem custo de minutos;
- espelho unidirecional: se o Forgejo cair, o GitHub tem o último `main` e todas as tags;
- backup diário do Forgejo (dump + repositórios, retenção de 14 dias).

### Sem mudanças funcionais

Nenhuma alteração em `src/` nesta versão: as thumbnails, hotkeys, spotlights, overlay e configuração
funcionam exatamente como na 8.2.2. Se você ainda não instalou a 8.2.2, atualize para esta: é o mesmo
ganho de CPU com a infraestrutura nova.

### Instalação

**Pacote completo** (`Release-v8.3.0-Linux.zip`, self-contained, roda também em Wine): substitua a
pasta inteira — o app usa `EveO.Core.dll`, `EveO.Infrastructure.dll` e `EveO.Presentation.dll`.

**Executável único** (`EVE-O-Preview-8.3.0-win-x64.zip`): para quem já tem o **.NET 8 Desktop Runtime**.

Mantenha seu `EVE-O-Preview.json` ao lado do executável — ele é compatível e não precisa ser reeditado.
Feche o EVE-O Preview antes de substituir.
