# EVE-O Preview 8.3.8 — fase 2 do layout (navegação em blocos)

Segunda etapa do estudo de layout. Inclui a fase 1 (8.3.7) quando instalada por cima de uma
versão anterior.

## Navegação em blocos

O `TabControl` lateral saiu. No lugar:

- **grade 4×2 de blocos**, cada um com ícone (`Segoe MDL2 Assets`) e rótulo;
- bloco selecionado com fundo de superfície e negrito;
- um host único para as telas, usando a **largura toda** da janela;
- a janela cresce de **455×251 para 455×388**.

## O que ficou igual

- as 8 telas continuam sendo as mesmas, com os mesmos controles nas mesmas posições
  relativas;
- config (`ConfigVersion: 2`), hotkeys, grupos, spotlight, labels e refresh intactos;
- o `TabControl` continua no Designer apenas como fonte das telas (oculto), o que evitou
  reescrever 1.500 linhas de layout de uma vez.

## Próximos passos do estudo

A fase 3 (tema escuro) continua como cosmético opcional, depois de esgotadas as melhorias.
