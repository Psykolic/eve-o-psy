# EVE-O Preview 8.3.3 — grupos de ciclo configuráveis na tela

Até aqui, configurar grupo de ciclo significava editar o `EVE-O-Preview.json` na mão — e
quem não achava o arquivo não configurava nada. Esta versão resolve isso.

## Aba Grupos

Nova aba na janela de configuração, entre *Active Clients* e *Spotlight*:

- cada grupo aparece com **os atalhos** e **os clientes na ordem de ciclagem**;
- grupo vazio em cinza, com "(sem atalho)";
- botão **Arquivo…** abre o JSON no editor padrão (ou a pasta, se ainda não existir).

## Editor de grupo

**Editar** (ou duplo clique no grupo) abre o diálogo:

| Campo | Como funciona |
|---|---|
| **Avançar** / **Retroceder** | clique no campo e **pressione a tecla**; a combinação é capturada no formato do arquivo (`F14`, `Control+F14`). **Backspace** limpa |
| **Clientes** | lista com todos os conhecidos; os **abertos agora** aparecem com ● e vêm primeiro |
| **▲ ▼** | definem a ordem de ciclagem |
| **Novo** | configura o primeiro grupo vazio |
| **Limpar** | esvazia o grupo |

Detalhes que fazem diferença no uso:

- **as teclas valem na hora** — salvar re-registra as hotkeys, sem reiniciar o aplicativo;
- **atalho repetido só avisa** (você pode estar trocando dois grupos ao mesmo tempo);
- **atalhos extras são preservados** — se o grupo tem `F14` e `Control+F14`, o diálogo mostra o
  principal e mantém o segundo;
- **a ordem que você definiu não é reescrita** ao salvar;
- enquanto o diálogo está aberto, as teclas de grupo ficam **suspensas** — digitar `F14` no campo
  não cicla os clientes no meio da edição.

## Importação do aplicativo anterior

Quem vem do EVE-O Preview antigo (`ConfigVersion: 3`, com `"CycleGroups"`) abria o app **sem grupo
nenhum**: as chaves não batem, e os grupos eram ignorados. Agora:

- os grupos são convertidos (até 5), com a ordem invertida corrigida (`posição → nome` passa a
  `nome → posição`);
- `CompatibilityMode` vira `WineCompatibilityMode`;
- o app avisa que importou, em vez de abrir silenciosamente sem atalhos.

## Sem mudanças

- interface de thumbnails, spotlight, hotkeys fora dos grupos — idênticos;
- formato de configuração continua `ConfigVersion: 2`; nenhuma dependência nova.
