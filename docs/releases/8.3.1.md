# EVE-O Preview 8.3.1 — Primeira release publicada no Forgejo

Esta é a primeira versão publicada inteiramente na forja própria: tag, build, smoke e asset saem do
Forgejo, sem o GitHub em nenhuma etapa.

**O aplicativo não muda.** Binário idêntico ao da 8.3.0 — nenhuma alteração em `src/`.

### O que mudou (infraestrutura e documentação)

- **release no Forgejo**: `scripts/release.sh vX.Y.Z` cria a tag e dispara o workflow, que builda o
  pacote `win-x64` self-contained, roda o smoke no Wine e anexa o asset;
- **repositório transferido** de `spike/*` para `psykolic/*`;
- **auto-merge** passou a ler o repositório do ambiente (não quebra mais em troca de dono);
- **histórico do GitHub arquivado** em `docs/audits/historico-github.md` (66 issues + 121 PRs);
- **C4** atualizado com o fluxo da fase 3.

### GitHub

O repositório no GitHub está **arquivado** (somente leitura). As releases antigas continuam
disponíveis para download; nada mais é publicado nem recebido por lá.

### Instalação

**Pacote completo** (`Release-v8.3.1.zip`, self-contained, roda também em Wine): substitua a pasta
inteira — o app usa `EveO.Core.dll`, `EveO.Infrastructure.dll` e `EveO.Presentation.dll`.

**Executável único** (`EVE-O-Preview-8.3.1-win-x64.zip`, quando presente): para quem já tem o
**.NET 8 Desktop Runtime** instalado.

Mantenha seu `EVE-O-Preview.json` ao lado do executável. Feche o EVE-O Preview antes de substituir.
