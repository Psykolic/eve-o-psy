# EVE-O Preview 8.3.2 — manutenção: erro previsível em vez de erro silencioso

**O aplicativo se comporta igual.** O que muda é o que acontece quando algo dá errado — e o
que você consegue enxergar quando ele começa a degradar.

## Configuração inválida não fecha mais o app

Antes, um `EVE-O-Preview.json` corrompido derrubava o aplicativo no carregamento. Agora ele
abre com os padrões e mostra o que corrigiu:

- JSON quebrado → abre com os padrões e explica o motivo;
- valor fora da faixa → avisa **qual chave**, o valor, a faixa e para quanto foi ajustado;
- valor com tipo inesperado (ex.: `"muito rápido"` num número) → mantém o valor anterior.

As faixas passaram a viver em um só lugar (`ConfigurationLimits`), usado tanto pelo aviso
quanto pelo ajuste — então o app não pode mais dizer uma coisa e fazer outra.

## Registro de thumbnail no DWM não vaza mais

O registro no DWM era um `IntPtr` solto: liberado só quando o fluxo de fechamento da view
passava por ali. Agora é um `SafeHandle` com finalizer — se a view fechar por qualquer
caminho, o registro volta para o DWM.

## Métricas opcionais (diagnóstico)

Com `EVE_METRICS=1`, o app grava uma linha a cada 30 s com o essencial para diagnosticar
problemas de convivência com vários clientes:

```
ts=2026-11-21T21:30:00Z refresh_ms=12.40 refreshes=1842 thumbnails=7 gdi=312 dwm=7 cpu_pct=1.4
```

Sem a variável, nada é gravado e nenhum comportamento muda.

## Testes

De **26 para 46 arquivos** de teste (Core: 130 → 151 casos). Cobrem os limites de cada
configuração, o hot-reload ao salvar, o ciclo de vida do handle DWM e a validação de arquivo
corrompido.

## Sem mudanças

- interface, hotkeys, ciclagem, spotlight, layout — idênticos;
- nenhuma dependência nova; nenhum formato de configuração novo (continua `ConfigVersion: 2`).

## Nota sobre a 8.3.1

A 8.3.1 foi a primeira release publicada inteiramente no Forgejo, com binário idêntico ao da
8.3.0. Esta 8.3.2 é a primeira com mudanças de código desde então.
